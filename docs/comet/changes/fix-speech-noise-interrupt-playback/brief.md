# 目标

修复真机语音助手当前暴露的五类问题，恢复「听得准、打得断、队列走得动、播得出、看得清」的日常体验：

1. **英文碎片误识别**：中文会话里 ASR 稳定冒出 The / Yeah / She 等纯英文虚词碎片，被当成用户说话展示或触发对话。
2. **打断 / 插话困难**：正在思考 / 播报时用户插话很难被响应，喊「小熊小熊」打断也不灵敏。
3. **队列卡死**：界面上已有排队中的句子（「我说」角标有排队数），但一直不被消费处理。
4. **播放失败提示**：点歌后出现「播放失败，可换个风格或检查网络」（客户端 `music.error`），需定位是哪个播放源失败并修复。
5. **竖屏播放条样式错乱**：竖屏时播放条「正在播放 歌名」标题逐字竖排、控制按钮挤压变形（截图已确认）；横屏正常。

# 范围

## 目录结构

### 修改

- `xiaoxiong-app/gateway/src/asr/noiseFilter.ts`：扩充英文虚词/代词碎片过滤（she / he / it 等稳定误识别词），保持「整段纯拉丁虚词、≤3 词」的拦截边界，不误伤英文正常短指令与中英混排。
- `xiaoxiong-app/gateway/src/service/voiceSessionService.ts`：核查 isNoise 在 finalize / 队列回放两条路径的覆盖；排查插话排队的准入条件（提示音清零、VAD 端点）与队列消费链（playback_done / skip_current 后的串行处理），修复卡死点。
- `xiaoxiong-app/uni_app/src/pages/index/index.vue`：播放条顶行布局修复——竖屏窄宽度下按钮区不再挤爆标题区（标题恢复横排，按钮可收纳 / 换行 / 收缩）。
- 播放失败：按真机复现定位失败源（B站 mp4 / SomaFM / gequbao 直链），在对应链路修复。

### 排查方式

- 真机 logcat（WakeModule / AudioPlayer）+ 设备网关日志区分「没收到 / 收到没处理 / 处理了没播」。
- 网关单测覆盖 noiseFilter 扩词、队列消费回归；UI 用竖屏截图 / CDP 验证。

# 非目标

- 不改唤醒词与打断的产品语义（「小熊小熊」打断当前句、普通话排队仍是既定约定）——本 change 只修「按约定却不生效」的部分。
- 不新增音乐播放源，不做黄历 / 商品等新直连功能。
- 不处理 H5-only 的问题（目标端只有 Android / iOS App）。

# 验收示例

- 中文会话里说或播放中出现 The / Yeah / She 这类纯英文虚词碎片，不被展示为用户说话、不触发对话回复；而「Taylor Swift 的歌」这类中英混排与英文正常短指令不受影响。
- 播报 / 思考期间插话能按现有约定排队；喊「小熊小熊」能跳过当前句并继续队列。
- 界面显示有排队句时，队列会继续被消费（播完一句接下一句），不再出现永久卡住。
- 点歌不再出现非预期来源导致的「播放失败，可换个风格或检查网络」；确因上游失败时提示如实反映。
- 竖屏播放条：标题横排完整显示、控制按钮排列整齐不互相挤压；横屏同样正常。
